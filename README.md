# Daily Quote — Cloudflare Pages Static Version

The full website runs both off of  both this repository and Cloudflare Pages, because I used run it off of my own server, but it wasn't powerfull enough and a better one is expensive.

## Quote Picking Info

The website picks one quote each day based on the date.

## Dark / Light Mode

A button in the top navigation switches between light mode and dark mode for visitor's desired choice (as some people prefer light over dark, or dark over light).
The browser remembers the user's choice with localStorage.
